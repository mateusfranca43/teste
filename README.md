# Neon Circuit 3D

Minigame de corrida 3D com apostas locais entre amigos. Quatro corredores têm estilos diferentes, mas chances equivalentes de vitória.

## Jogar

Abra a página publicada no GitHub Pages ou baixe `index.html` e abra em um navegador moderno.

## Balanceamento

- Odds iguais de 4,0×.
- Variação de forma individual entre -10% e +10% por corrida.
- Perfis preservados: Conservador, Sprinter, Caótico e Equilibrado.
- Validação determinística com 100.000 corridas: cada corredor venceu entre 24,10% e 27,03%.

Participantes, saldos e apostas são armazenados apenas no navegador (`localStorage`).
